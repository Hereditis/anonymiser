Les pièces sont lues et traitées dans votre navigateur, sur votre poste. La page s'interdit tout accès à Internet par sa propre politique de sécurité : vous pouvez couper votre connexion avant de commencer. Rien n'est conservé à la fermeture de l'onglet.

1Le foyer

Saisissez les personnes et les sociétés du dossier, ou laissez l'outil les trouver avec le bouton « Détecter le foyer » de l'étape 2. Tout ce qui figure ici sera masqué dans toutes les pièces ; le libellé est ce qui remplacera le nom.

2Les pièces

    4Exporter
    
  
    Les pièces pseudonymisées sont prêtes à être transmises. La table de correspondance, elle, reste chez vous : c'est elle qui permet de rétablir les noms dans le bilan reçu.
    
  
    
  
    
    
    
  
    
  
    Pièce par pièce
    
  
      
  
      La table de correspondance contient les vrais noms. Conservez-la dans le dossier du client et ne la joignez jamais à l'envoi.
      

      


      
  
      5Rétablir les noms dans un document reçu
      
  
      Vous avez reçu le bilan avec des libellés comme [Client 1] ? Chargez votre table de correspondance et le document (.docx, .pptx, .xlsx ou .txt) : les vrais noms sont remis en place, sur votre poste.
